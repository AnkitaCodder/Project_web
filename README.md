# 🏠 House Rental System

This is a simple **House Rental Management System** built using **HTML, CSS, PHP, and MySQL**.  
It allows users to browse available houses, manage rental details, and store data in a database.  

 ✨ Features
- User registration & login
- Add and manage rental properties
- Search available houses
- Book or rent a house
- Store data in MySQL database
- Simple and responsive UI

🛠️ Tech Stack
- Frontend: HTML, CSS  
-  Backend: PHP  
- Database: MySQL
